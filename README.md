# 5-Build
Module 5 Build

##Project Summary: The Indie Film Collective is a creative community dedicated to independent filmmakers, storytellers, and visual artists. This website provides information about film screenings, filmmaking workshops, and opportunities for creative collaboration.

##Website Pages: the website has four main pages as follows
*1. home (index.html): intro for Indie Film Collective and its mission
*2. Film Screenings (screenings.html): highlights films and upcoming screenings
*3. Workshops (workshops.html): gives info about filmmaking workshops
*4. Collaborations (collaborations.html): explores opportunities to connect and work with others

##Technologies used
*1. HTML
*2. CSS
*3. Responsive design using CSS Grid and media queries
